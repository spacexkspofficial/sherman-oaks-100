    Editor Notes

    How to add or edit entries

    The map data lives in a JavaScript array at the bottom of this notable-residents.html page. Each entry is a small object with name, era, coordinates, bio, and source citation. Adding a new pin is a single edit.

    Sourcing & consent policy

    • Cite every entry. Source field should reference a biography, newspaper archive, property record, school record, or family contribution.
    • Living people: use block-level approximate coordinates only — never exact home addresses. Obtain consent before publishing if practical.
    • Deceased figures: approximate coordinates are still strongly preferred unless the location is a museum, marker, or otherwise public.
    • Tag placeholders. Unverified entries should keep the placeholder: true flag so the sidebar shows a "to be verified" badge.

    Getting coordinates

    The simplest way: open Google Maps, right-click on the spot you want, and click the latitude/longitude that appears at the top of the menu. Paste those numbers into the coords: [lat, lng] field. For privacy on living people, drop the pin a block or two off the actual address.
